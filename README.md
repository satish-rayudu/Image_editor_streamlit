# 🖼️ Image Editor Web App

An interactive Image Editing Web Application built using **Python, Streamlit, and OpenCV** that allows users to upload images and apply real-time image processing effects through a simple and user-friendly interface.

---

## 🚀 Features

* 📤 Upload images instantly
* 🌫️ Apply Blur effect
* ✨ Sharpen images
* ☀️ Adjust Brightness
* 🎚️ Control Contrast
* ⚫ Convert to Grayscale
* 📌 Edge Detection using OpenCV
* 🆚 Side-by-side image comparison
* 📥 Download edited images

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **OpenCV**
* **NumPy**
* **Pillow**

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone <your-github-repo-link>
```

### 2️⃣ Navigate to Project Folder

```bash
cd image-editor-app
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
streamlit run app.py
```
